## Why PACKS stayed queued

The page only inserted a Supabase job. No worker was running; no persistent worker email/password was configured; the default Python environment lacked its audio dependencies. The watchdog silently skipped the worker. Job creation/poll errors were also swallowed and jobs were not restored after reloading the page.

ScrewShop now saves locally and runs its processor inside the local service. It checks readiness, atomically claims one job, suppresses duplicate active jobs, restores job status on reload, exposes useful errors, rejects missing sources, verifies every expected output, and marks interrupted jobs retryable.

## Security changes

Local disk database with parameterized SQL and constrained tables; no browser Supabase credentials or remote storage; same-origin writes with a required custom header; Host checks against DNS rebinding; paired devices required for LAN data access; HttpOnly/SameSite cookies and Secure cookies on HTTPS; bounded upload/decode/job execution; no shell interpolation for media; audio extension allowlist; data, TLS secrets and repository files outside the static web root; local vendored browser libraries; source audio retained for recovery.

Dependencies: torch 2.14.0+cpu, torchaudio 2.11.0+cpu, Demucs 4.0.1, SoundFile 0.14.0, NumPy 2.4.6, imageio-ffmpeg 0.6.0, cryptography 50.0.1, setuptools 84.0.0. SoundFile handles model I/O so the app does not depend on deprecated torchaudio file APIs. Models come from Demucs' built-in upstream registry and use upstream checksum verification; user-supplied model files are not accepted.
