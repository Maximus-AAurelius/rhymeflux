1BARWORK — a rap writing studio, feature-complete
What this is — the full feature set from the brief: song library, writing editor with live rhyme colouring and per-bar syllable counts, the tap-a-word drawer (rhymes / swaps / multis, ranked by tier), beat source + loop markers, the 4/4 beat grid and section structure, a booth for line-by-line takes, the vibe-conditioned AI co-writer with rhyme verification, sensitivity settings, and Free/Pro/Lifetime pricing. Original interface on the Modernist system — flush-left, no radii, 2px rules, one red accent; rhyme families read as fill weight plus ink/red alternation rather than a rainbow.

It runs on the real engine. rhyme-engine.js is the framework-agnostic module from milestone 1 — curated ARPAbet over a slang overlay over rule-based G2P, weighted phoneme edit distance from the last stressed vowel, tiers (perfect / family / slant / assonance), in-process memo cache, and getRhymes() / getSyllableCount() / verifyRhyme() / rhymeFamilies() as the only public surface. The editor never waits on it: until it loads, a local spelling heuristic keeps colouring. Assertions and a live scorer are in Engine Bench. CMUdict (134k entries) drops in between the curated lexicon and the overlay without changing a line above it — GitHub's importer won't carry cmudict.dict, so that load stays a backend data step.
